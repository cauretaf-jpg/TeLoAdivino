TeLoAdivino v7.0 · Pulido de producto

Cambios principales:
- Onboarding inicial de 4 pasos para nuevos usuarios.
- Avatares automáticos por participante en salas y listados.
- Sala online más visual: barra de actividad, participantes activos y etiquetas de anfitrión.
- Microinteracciones y transiciones suaves entre pantallas.
- Sonidos generados por navegador para taps, respuestas, resultado y ruleta.
- Tarjetas de juego con etiquetas visuales por tipo de experiencia.
- Refuerzo CSS definitivo para que la barra inferior quede dentro del flujo normal y no tape contenido.
- Cache actualizada a v7.0.

Notas:
- Los sonidos se activan después de la primera interacción del usuario, según las restricciones normales del navegador.
- Las salas siguen usando Firebase Realtime Database.
- Si ves una versión anterior, prueba abrir con ?v=700 o reinstalar la PWA.
